\begin{abstract}
{\sloppy
On-device zero-shot neural voice cloning enables the localized replication of an unseen human speaker's acoustic timbre and prosody from a brief reference recording (three to five seconds) without model fine-tuning or server communication. Performing voice cloning directly on edge devices provides complete biometric data privacy, ensuring that voiceprints never leave the physical device while enabling full offline operation in bandwidth-constrained environments. However, executing modern generative speech models on consumer edge hardware introduces difficult memory and compute constraints. Commodity edge platforms, such as the budget Lenovo Tab K10 tablet (MediaTek Helio P22T with 4\,GB RAM), lack discrete graphics hardware, have limited memory bandwidth, and enforce strict physical memory limits before the Linux kernel's \textit{LowMemoryKiller} terminates user processes. In addition, existing edge text-to-speech engines predominantly support English phonology, failing to accommodate Dravidian and Indo-Aryan languages characterized by complex syllabic structures (\textit{aksharas}), consonant conjuncts, and vowel ligatures.

This report develops an offline, multilingual zero-shot voice cloning pipeline that operates within the resource limits of commodity Android hardware. We implement a dual-engine architecture consisting of: (i) an optimized English baseline using a non-autoregressive Zipformer backbone (ZipVoice-Distill, 123M parameters, INT8 quantized to 104\,MB) with a 24\,kHz Vocos vocoder executed via Sherpa-ONNX; and (ii) an Indic voice cloning engine based on a 22-layer Diffusion Transformer (IndicF5, 335M parameters) adapted from AI4Bharat's 1,417-hour multilingual foundation model. To satisfy edge memory budgets, we apply static INT8 quantization and pre-allocated memory arenas, reducing the IndicF5 DiT from 1.35\,GB down to 349\,MB and the Vocos vocoder to 22\,MB, which bounds peak resident memory to 801\,MB. We formulate a calibrated on-device syllabic duration model (6.5 mel frames per character) that eliminates grapheme-to-phoneme rule dictionaries, and engineer a native C++ runtime engine for mobile execution. Physical hardware profiling across four ARM device tiers validates process stability without out-of-memory terminations. Finally, we formulate a concrete production roadmap targeting Google LiteRT and hardware neural processing units (Qualcomm QNN HTP and MediaTek NeuroPilot), establishing that high-fidelity multilingual voice cloning can be achieved entirely at the edge.
\par}
\end{abstract}
