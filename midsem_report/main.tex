\begin{abstract}
{\sloppy
On-device zero-shot neural voice cloning enables the localized replication of an unseen human speaker's acoustic timbre and prosody from a brief reference recording (three to five seconds) without model fine-tuning or server communication. Performing voice cloning directly on edge devices provides absolute biometric data privacy—ensuring that sensitive human voiceprints never leave the physical device—while granting full operational autonomy in network-disconnected or bandwidth-constrained environments. However, executing modern high-capacity generative speech models on consumer edge hardware presents profound architectural and systems-level hurdles. Commodity edge platforms, exemplified by budget Android tablets such as the Lenovo Tab K10 (MediaTek Helio P22T with 4\,GB RAM), operate without server-grade graphics accelerators, possess restricted memory bandwidth, and enforce strict physical memory ceilings before the Linux kernel's \textit{LowMemoryKiller} forcibly terminates user applications. Furthermore, existing edge text-to-speech engines predominantly support English phonology, failing to accommodate Dravidian and Indo-Aryan languages characterized by complex syllabic structures (\textit{aksharas}), consonant conjuncts, and vowel ligatures.

This report addresses the foundational challenge of realizing multilingual zero-shot voice cloning strictly confined within the physical resource constraints of commodity edge devices. We design and implement a dual-engine edge architecture comprising: (i) an optimized English baseline using a non-autoregressive Zipformer backbone (ZipVoice-Distill, 123M parameters, INT8 quantized to 104\,MB) and a 24\,kHz Vocos vocoder executed via Sherpa-ONNX; and (ii) an Indic voice cloning engine based on a 22-layer Diffusion Transformer (IndicF5, 335M parameters) adapted from AI4Bharat's 1,417-hour multilingual foundation model. To satisfy strict edge memory budgets, we formulate a static INT8 quantization and memory arena strategy that compresses the IndicF5 DiT from 1.35\,GB down to 349\,MB and the Vocos vocoder to 22\,MB, maintaining an 801\,MB operational memory footprint. We develop a calibrated on-device syllabic duration model (yielding 6.5 mel frames per character) eliminating external grapheme-to-phoneme dictionaries, and engineer a native C++ runtime engine for mobile execution. Physical hardware profiling across diverse ARM platforms confirms edge stability without system crashes. Finally, we formulate a production roadmap to Google LiteRT leveraging edge neural processing units (Qualcomm QNN HTP and MediaTek NeuroPilot), establishing that high-fidelity voice cloning can be achieved entirely at the edge.
\par}
\end{abstract}
